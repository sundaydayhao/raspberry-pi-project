# 🌐 IoT Web 传感器项目集合

本目录包含5个完整的树莓派IoT Web项目，每个项目都能将传感器数据通过WiFi上传到网页，
支持PC和手机访问。所有项目均包含**模拟模式**，无需硬件即可在PC上测试运行。

---

## 项目总览

| # | 项目名称 | 文件 | 端口 | 传感器 | 特色功能 |
|---|---------|------|------|--------|---------|
| 1 | 🏠 智能家居环境监测站 | `smart_home_monitor.py` | 5000 | DHT11+BMP280+MQ-2+PIR | 报警横幅、运动日志 |
| 2 | 🌱 智能植物养护系统 | `plant_care_web.py` | 5001 | 土壤湿度+DHT11+光照 | 自动浇水、远程控制 |
| 3 | 📊 实时多传感器仪表盘 | `realtime_dashboard.py` | 5002 | 温湿度+超声波+光照+加速度 | WebSocket推送、CSV导出 |

## 🚀 快速开始

### 1. 安装依赖
```bash
pip3 install flask flask-socketio eventlet
pip3 install Adafruit-DHT spidev smbus2
pip3 install opencv-python  # 可选，用于摄像头
```

### 2. 运行任意项目（模拟模式，无需硬件）
```bash
# 项目1：智能家居环境监测站
python3 08-iot-projects/smart_home_monitor.py

# 项目2：智能植物养护系统
python3 08-iot-projects/plant_care_web.py

# 项目3：实时多传感器仪表盘（WebSocket）
python3 08-iot-projects/realtime_dashboard.py

# 项目4：智能安防监控系统
python3 09-advanced-projects/smart_security_web.py

# 项目5：智能电能监测系统
python3 09-advanced-projects/energy_monitor_web.py
```

### 3. 访问网页
- **本机访问：** `http://localhost:<端口>`
- **局域网访问：** `http://<树莓派IP>:<端口>`
- **手机访问：** 确保手机与树莓派在同一WiFi，访问上述局域网地址

## 📱 项目详细说明

### 🏠 项目1：智能家居环境监测站（端口5000）

**适合场景：** 家庭/办公室环境监测

**Web界面功能：**
- 5个实时数据卡片（温度、湿度、气压、烟雾状态、运动状态）
- 3个历史趋势折线图（温度/湿度/气压，最近100次采样）
- 超限自动报警横幅（温度/湿度/烟雾）
- 运动检测日志（最近20条）
- 每3秒自动刷新

**硬件清单：**
```
DHT11温湿度传感器  × 1
BMP280气压传感器   × 1（I2C）
MQ-2烟雾传感器    × 1
PIR人体感应模块   × 1
```

---

### 🌱 项目2：智能植物养护系统（端口5001）

**适合场景：** 阳台/室内植物自动养护

**Web界面功能：**
- 植物状态大图标（🌿正常/🥀缺水/🏜️严重缺水/🌊水多）
- 4个数据卡片（土壤湿度/温度/空气湿度/光照，含进度条）
- 浇水控制面板（手动浇水/停止/自动模式切换）
- 土壤湿度和温度历史趋势图
- 浇水历史记录（时间/时长/触发方式/浇水前湿度）

**自动浇水逻辑：**
```
土壤湿度 < 40% → 自动触发水泵（5秒）→ 冷却300秒 → 再次检测
```

**硬件清单：**
```
电容式土壤湿度传感器  × 1
DHT11温湿度传感器    × 1
光敏电阻（LDR）      × 1
MCP3008 ADC芯片     × 1
5V继电器模块         × 1
微型水泵             × 1
```

---

### 📊 项目3：实时多传感器仪表盘（端口5002）

**适合场景：** 多传感器数据可视化学习/展示

**技术亮点：**
- 使用 **Flask-SocketIO + WebSocket** 实现服务器主动推送
- 无需轮询，数据延迟 < 100ms
- 支持多客户端同时连接

**Web界面功能：**
- 6个指标卡片（温度/湿度/距离/光照/加速度/舒适度）
- 4个实时折线图（温湿度/距离/光照/加速度三轴）
- 加速度三轴可视化柱状图（动态高度）
- 一键导出CSV数据文件
- WebSocket连接状态指示灯

**硬件清单：**
```
DHT11温湿度传感器   × 1
HC-SR04超声波模块   × 1
MPU6050加速度陀螺仪 × 1（I2C）
光敏电阻（LDR）     × 1
MCP3008 ADC芯片    × 1
```

---

### 🔒 项目4：智能安防监控系统（端口5003）

**适合场景：** 家庭/办公室安防监控

**Web界面功能：**
- 布防/撤防一键切换（带动画效果）
- 入侵报警横幅（红色闪烁）
- 3个统计卡片（累计报警/今日报警/当前距离）
- 超声波距离实时图表（含红色警戒线）
- 报警日志（时间/原因/来源/缩略图）
- 入侵快照画廊（点击查看大图）

**报警触发条件：**
```
布防状态下：
  PIR检测到人体 → 触发报警 + 蜂鸣器 + 拍照
  超声波距离 < 80cm → 触发报警 + 蜂鸣器 + 拍照
```

**硬件清单：**
```
PIR人体感应模块    × 1
HC-SR04超声波模块  × 1
有源蜂鸣器         × 1
USB摄像头          × 1（可选）
```

---

### ⚡ 项目5：智能电能监测系统（端口5004）

**适合场景：** 家庭用电监测/节能分析

**Web界面功能：**
- 4个主要指标（电压/总功率/累计用电量/累计电费）
- 各路负载卡片（电流/功率/用电量/通断状态/功率进度条）
- 实时总功率折线图
- 各路负载功率对比柱状图
- 每小时用电统计表

**计算公式：**
```
功率(W) = 电压(V) × 电流(A)
用电量(kWh) = 功率(W) × 时间(h) / 1000
电费(元) = 用电量(kWh) × 单价(元/kWh)
```

**硬件清单：**
```
ACS712电流传感器  × 3（5A/20A/30A根据负载选择）
分压电路          × 1（电压检测）
MCP3008 ADC芯片  × 1
```
